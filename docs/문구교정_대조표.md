## 2. 유지한 문구와 근거

| 문구 | 유지 이유 |
| :--- | :--- |
| 「1등급 내신 대비의 전략적 표준」 | 사용자가 정한 슬로건. §11.2 사용자 직필 보존 |

| 「단순 양치기 문제 은행 유저」 | 사용자 원안의 배제 대상 서술. 금지 패턴(§8.2)에 해당하지 않음 |

## 4. 미적용 범위

- `docs/`의 팀 내부 문서 2건은 이번 교정 대상에서 제외했습니다. 발표 자료가 아니고, 원안 문장을 보존할 필요가 있습니다.
- 목업 UI의 수학 문항 본문은 실제 시험지 문체를 따랐으므로 산문 규칙을 적용하지 않았습니다.
- 애니메이션·레이아웃은 변경하지 않았습니다. 문구 길이 변화로 줄바꿈이 달라진 화면은 렌더링해 확인했습니다.
