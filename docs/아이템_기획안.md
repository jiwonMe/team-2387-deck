# [TEAM 2387] 아이템 기획안 v4 — 고1·고2 수학 내신 대비 플랫폼

> **v4 변경 요약 (맥킨지 CDD 검토 반영)**
> 1. **민감정보 진입점 제거** — 부교재 통째 업로드 → 시중 20종 **사전 메타DB에서 선택**, 학교 기출만 촬영·즉시 파기
> 2. **가치제안 고도화** — 단원 비중 히트맵 → **출처 역추적**: "작년 22문항 = 부교재 숫자변형 41% · 조건추가 23% · 학평킬러 18% · 교과서 18%"
> 3. **공급망 명시** — 검수 40%의 원천 = ① 교육청·평가원·EBS **공공기출 재해설 DB** ② **대성학력개발연구소 비독점 라이선스** ③ 자체 검수 강사 풀(문항당 2~3분 × 시급 1.5만 = 500~750원)
> 4. **GTM 전환** — 초기엔 그 학교 **1등급 인원(8~10명)을 정원으로 선착순 딜 클로즈**, 궤도(재결제 60%) 후 전체 오픈 → 적자 학교 0
> 5. **단위경제 재설계** — 단일 시나리오 → **5명(BEP) / 10명(공헌이익 43%) / 20명(59%)** 3 시나리오 + 민감도
> 6. **시장규모** — 하향식 7.8조 → **Bottom-up: 1,200교 × 72명 × 2학기 × 15만 = SAM 약 260억 / 3년 SOM 26억**
> 7. **Kill-switch KPI** — 5인 개설 성공률 ≥40% · 검수 탈락률 ≤10% · 재결제율 ≥60%
>
> 발표용 최신본은 `web/` (Astro) 이며, 이 문서는 팀 공유용 요약입니다.


> 정의가 바뀌었습니다. **입력 3종 → 학교 출제 프로필 → 출력 2종** 구조로 읽으면 됩니다.

## 한 줄 정의
> 학생이 올린 **부교재**, 그 학교의 **과거 기출**, **최근 학평**을 비교·분석해 **내신에 나올 문항을 새로 생성**하고, **기존 검수 문항**과 함께 제공하는 **고1·고2 수학 내신 대비 플랫폼**

| 항목 | 내용 |
| :--- | :--- |
| Input | 부교재 · 학교 기출 · 최근 학평 |
| Output | **신규 생성 문항** + **기존 검수 문항** |
| Scope | 고1·고2 수학 (고3·수능·국영·해외 제외) |
| Model | 학기 패스 |

## 02. 무엇이 들어가서 무엇이 나오나

```
[Input 1] 부교재      ┐
[Input 2] 학교 기출   ├─ compare · match ─▶  학교 출제 프로필 + 비교 리포트
[Input 3] 최근 학평   ┘                              │
                                          generate · assemble
                                                     ▼
                            [Output 1] 신규 생성 문항
                            [Output 2] 기존 검수 문항
```

- **부교재**: 학생이 올린 교재의 단원·유형·난도 구조를 파싱해 범위에 매핑
- **학교 기출**: 어느 단원에서 몇 문항, 어떤 유형이 반복되는지
- **최근 학평**: 최신 출제 경향, 내신 변형의 원형이 되는 문항군
- **Engine**: 세 입력의 교집합과 갭을 계산 → "이 학교는 부교재 3단원에서 40%, 학평 유형 2개가 반복" 같은 근거 생성
- **출력**: 생성 문항은 3단 검증 통과분만, 검수 문항은 품질 하한선 역할

---

## 03. 차별점은 비교 리포트

- **보여주는 것** — 부교재 단원 × 기출 빈도 × 학평 유형을 한 장에 겹쳐 **출제 우선순위로 정렬**
- **증명하는 것** — 시험 후 실제 출제와 대조해 **적중률을 리포트로 회수** → 다음 학기 프로필 정확도 상승
- **막는 것** — ChatGPT로 만든 문항에는 근거가 없음. 우리는 **근거 화면 → 문항 → 해설**이 한 줄로 연결

**품질 원칙**: 최상위 모델도 수학 문항 5개 중 1개는 교사 기준 미달(3항목 동시 충족 78.8%). 따라서 세트의 일정 비율은 **반드시 검수 문항**으로 채우고, 생성 문항은 **자동 검증 → 교과 검수 → 강사 최종 확인** 통과분만 노출.

## 04. 법적으로 어떻게 버티나

업로드를 받는 순간 "원본 미보관" 하나로는 부족합니다. 3중 방어로 설계합니다.

| 항목 | 원칙 |
| :--- | :--- |
| 업로드 | **분석 후 즉시 파기** — 남기는 것은 단원·유형·난도 구조 정보와 학교 프로필뿐 |
| 기출 | 원본 **축적·공유 안 함**. 통계(빈도·유형)만 보존, 타 학생 노출 경로 차단 |
| 생성 문항 | 원문 재배열이 아니라 **개념·유형·난도 정보를 근거로 새로 창작**. 원본 문장·도형·수치 미복제 |
| 열람 권한 | 학교 단위로만 열람, 교사는 **옵트인** 참여, 배포 경로 차단 |

## 05. 어떻게 돈을 버는가

| 단계 | 상품 | 설명 |
| :--- | :--- | :--- |
| 1단계 · 핵심 | 수학 학기 패스 | 인강(월 13.5만)과 학원(월 56만) 사이 가격대. 학원 대체가 아닌 보완재 |
| 2단계 · 확장 | 학교별 수학 특강 | 학생이 모인 학교부터 개설 |
| 3단계 · 확장 | 지역 학원 B2B2C | 동네 학원 비독점 파트너, 원생 대상 광고 금지 |

**승부수 — "학교당 5명이면 손익분기"**
학기 300문항 세트를 학교 전체가 공유. 문항당 생성 200원 + 검수 인건비를 더해도 학교당 콘텐츠 원가 20만 원대, 업로드 분석·운영비를 합쳐도 **학교당 5명 안팎이면 남는 구조**.

## 06. 왜 우리가 오래 갈 수 있나

- **Data** — 부교재·기출·학평 비교 이력과 적중 결과 축적. 쓸수록 리포트가 정확해짐
- **Review** — 생성은 누구나 하지만, 통과 기준과 검수 파이프라인은 시간이 걸리는 자산
- **Contract** — 출판사 정식 허락, 지역 학원 제휴

## 07. 이번 주에 만들 것 (프로토타입 5화면)

고1 수학 × 1개 학기 × 20개 학교

1. **업로드** — 부교재·범위 입력, "분석 후 파기" 고지 포함
2. **비교 리포트** — 부교재 × 기출 × 학평 겹친 화면 (**발표 하이라이트**)
3. **문항 세트** — 생성 + 검수 혼합, 검증 배지 표시
4. **오답 → 해설** — 문항별 판서 해설 → 취약 단원 반복
5. **적중 리포트** — 시험 후 실제 출제와 대조 → 다음 학기 개선
